Harbor Heat is an original top-down open-world crime game set in the port city of Porto Azul. You play Rico, a courier who owes $2,000 to a loan shark named Marlin. Drive taxis, steal cars, run risky drops, and outrun the police across six story missions in a living city with traffic, pedestrians, a wanted-star system, cash pickups, and a minimap. The game runs fully offline in a desktop browser from static files, with keyboard and mouse controls.

## Run it

```sh
# Option 1: open the game directly
#   open game/index.html in a desktop browser

# Option 2: serve the game folder locally
npx serve game
```
